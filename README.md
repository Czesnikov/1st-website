# patrol114 — green/grey redesign

Standalone HTML/CSS/JS implementation inspired by the supplied patrol114.pl portfolio structure.

Changes requested:
- green + grey visual system
- cursor-reactive triangular background mesh instead of graph-like visuals
- central double helix rebuilt from straight, angular SVG segments
- responsive layout
- no JS framework required

Run locally:
    python -m http.server 8000

Then open:
    http://localhost:8000/

The avatar is referenced from the original public site URL. Replace it with a local asset if you want the clone to be fully self-contained.
